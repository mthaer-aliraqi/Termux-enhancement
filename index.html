1. التثبيت الأولي

  1. ثبّت Termux من F-Droid، لأن نسخة Play Store قديمة ولا تُحدَّث.
  2. ثبّت Termux:API من F-Droid، لربط Termux بوظائف الهاتف.
  3. اختياري: ثبّت Termux:Styling لتغيير الخط من واجهته.
كل التطبيقات الثلاثة يجب أن تكون من F-Droid حتى تعمل معًا.

2. أول إعداد

حدّث الحزم أولًا:

pkg update -y && pkg upgrade -y

ثم امنح Termux الوصول إلى ملفات الهاتف مرة واحدة:

termux-setup-storage

بعدها تظهر ملفات الهاتف في ~/storage/shared، والتنزيلات في ~/storage/downloads.

3. الأساسيات والاختصارات

  • Tab: يكمل الاسم تلقائيًا.
  • ↑ ↓: يتنقل بين الأوامر السابقة.
  • Ctrl+C: يوقف الأمر الجاري.
  • Ctrl+D أو exit: يغلق الجلسة.
  • Ctrl+L أو clear: يمسح الشاشة.
  • Ctrl+R: يبحث في السجل.
  • لصق النص: اضغط مطولًا على الشاشة ثم اختر Paste. لا يعمل Ctrl+V.

فهم أي أمر قبل تشغيله

pkg install tldr -y
tldr ls

4. التنقل وإدارة الملفات

pwd                  # أين أنا؟
ls -lah              # ما الموجود هنا بالتفصيل؟
cd ~                 # المجلد الرئيسي
cd ..                # الخروج من المجلد الحالي
cd ~/storage/shared  # ذاكرة الهاتف
mkdir -p مجلد       # إنشاء مجلد
cp ملف نسخة        # نسخ ملف
cp -r مجلد نسخة    # نسخ مجلد
mv قديم جديد       # نقل أو إعادة تسمية
تحذير: rm يحذف نهائيًا ولا توجد سلة مهملات. تأكد من الاسم قبل تنفيذه.

5. تحرير الملفات

nano ملف.txt
  • Ctrl+O ثم Enter: حفظ.
  • Ctrl+X: خروج.
  • Ctrl+K: حذف السطر الحالي.

لمحرر يعمل باللمس والفأرة:

pkg install micro -y

6. zsh: الألوان والإكمال

zsh شِل أحدث من الافتراضي، وفيه إكمال تلقائي وقائمة اختيار بالأسهم وتلوين للأوامر.

الخطوة 1: التثبيت وجعله الافتراضي

pkg install zsh git -y
chsh -s zsh

أغلق Termux وافتحه من جديد.

الخطوة 2: تحميل الإضافات

git clone https://github.com/zsh-users/zsh-autosuggestions ~/.zsh/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting ~/.zsh/zsh-syntax-highlighting

الخطوة 3: إعدادات الألوان والإكمال

cat >> ~/.zshrc << 'EOF'

autoload -Uz colors && colors
PROMPT='%F{magenta}%B🐧 %b%F{yellow}📁 %~ %F{green}❯%f '

autoload -Uz compinit && compinit
zmodload zsh/complist
zstyle ':completion:*' menu select
zstyle ':completion:*' matcher-list 'm:{a-zA-Z}={A-Za-z}'
zstyle ':completion:*' list-colors "${(s.:.)LS_COLORS}"
bindkey -M menuselect '^[[Z' reverse-menu-complete

autoload -U up-line-or-beginning-search
autoload -U down-line-or-beginning-search
zle -N up-line-or-beginning-search
zle -N down-line-or-beginning-search
bindkey '^[[A' up-line-or-beginning-search
bindkey '^[[B' down-line-or-beginning-search

[ -f ~/.zsh/zsh-autosuggestions/zsh-autosuggestions.zsh ] && source ~/.zsh/zsh-autosuggestions/zsh-autosuggestions.zsh

typeset -A ZSH_HIGHLIGHT_STYLES
ZSH_HIGHLIGHT_STYLES[command]='fg=green,bold'
ZSH_HIGHLIGHT_STYLES[alias]='fg=cyan,bold'
ZSH_HIGHLIGHT_STYLES[unknown-token]='fg=red,bold'
source ~/.zsh/zsh-syntax-highlighting/zsh-syntax-highlighting.zsh
EOF
source ~/.zshrc
النتيجة: موجّه ملوّن، واقتراحات رمادية أثناء الكتابة، أوامر صحيحة باللون الأخضر وخاطئة باللون الأحمر، والأسهم تبحث في السجل.

7. الأيقونات والخط

عرض الملفات بأيقونات وألوان

pkg install eza bat -y

خط يدعم الأيقونات (Nerd Font)

pkg install unzip -y
curl -L -o ~/jbm.zip https://github.com/ryanoasis/nerd-fonts/releases/download/v3.2.1/JetBrainsMono.zip
unzip -o ~/jbm.zip -d ~/jbm
mkdir -p ~/.termux

أغلق Termux وافتحه من جديد لتظهر الأيقونات.

8. المقتطفات والإكمال بـ Alt+S

المقتطف أمر طويل تحفظه باسم قصير، ثم تختاره من قائمة بحث بضغطة واحدة بدل حفظه في ذاكرتك.

الخطوة 1: تفعيل النظام

pkg install fzf -y

cat >> ~/.zshrc << 'EOF'
snipadd() { sed -i "/^$1|/d" ~/.snippets.txt 2>/dev/null; echo "$1|$2" >> ~/.snippets.txt && echo "saved: $1"; }
snipls()  { cat ~/.snippets.txt 2>/dev/null | column -t -s'|'; }

snip-pick() {
  local cmd
  cmd=$(cut -d'|' -f2- ~/.snippets.txt 2>/dev/null | fzf --height 40% --reverse --prompt='snippet> ')
  [[ -n $cmd ]] && LBUFFER+="$cmd"
  zle reset-prompt
}
zle -N snip-pick
bindkey '\es' snip-pick
EOF
source ~/.zshrc

الخطوة 2: إضافة مقتطفاتك

snipadd "update" "pkg update -y"
snipadd "upgrade" "pkg update && pkg upgrade -y"
snipadd "storage" "termux-setup-storage"
snipadd "git-status" "git status"
snipadd "py-version" "python --version"
snipadd "clear" "clear"

الخطوة 3: الاستخدام

  • Alt+S: يفتح القائمة. اختر بالأسهم أو اكتب للبحث، ثم Enter لكتابة الأمر في السطر.
  • snipls: يعرض كل المقتطفات المحفوظة.
زر Alt في Termux موجود في الصف الإضافي فوق الكيبورد. اضغطه ثم S.

منع التكرار

awk -F'|' '!seen[$1]++' ~/.snippets.txt > ~/.snippets.tmp && mv ~/.snippets.tmp ~/.snippets.txt

النسخة الاحتياطية

cp ~/.zshrc ~/.snippets.txt ~/storage/shared/

9. تثبيت الأدوات وجعلها افتراضية

ثبّت الأدوات التي تحتاجها مرة واحدة:

pkg install eza bat tldr htop fzf micro -y

جعلها تعمل تلقائيًا عند كتابة الأمر العادي

أضف هذه الاختصارات إلى zsh، فتعمل الأدوات بدل الأوامر الأساسية:

cat >> ~/.zshrc << 'EOF'
alias ls='eza --icons --color=always --group-directories-first'
alias ll='eza -lah --icons --color=always --group-directories-first'
alias tree='eza --tree --icons --color=always --level=2'
alias cat='bat --paging=never --style=plain'
alias top='htop'
EOF
source ~/.zshrc

التحقق

echo $0          # يجب أن يظهر zsh
ll               # قائمة ملفات بأيقونات
which zsh        # مسار zsh
إذا أردت العودة إلى الإعداد الأساسي، فاحذف السطور المضافة من ~/.zshrc باستخدام nano.

10. أدوات البرمجة

pkg install python python-pip openjdk-17 nodejs -y
python --version && java -version && node --version && git --version
  • Python: python ملف.py
  • Java: javac ملف.java && java اسم_الكلاس
  • Node.js: node ملف.js
  • Git: git add -A && git commit -m "رسالة"

إعداد Git مرة واحدة

git config --global user.name "اسمك"
git config --global user.email "بريدك"
